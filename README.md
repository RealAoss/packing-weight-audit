# Packing Weight Audit

Compare packed items and quantities against a baggage weight allowance.

Open `index.html` in a modern browser. Edit the sample inputs to update the result, then print or download it. Processing stays in the tab.

## Example

Input:

```text
10
Books | 3 | 2
Bag | 1 | 1
```

Expected output includes:

```text
Remaining: 3.00 kg
```
